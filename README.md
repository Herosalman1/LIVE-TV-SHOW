# LIVE-TV-SHOW

A simple static website hosted on GitHub Pages.

## Project Structure
- `index.html` — main website page
- `admin.html` — admin page for managing channels
- `tools.json` — channel data
- `README.md` — project documentation
- `COPYRIGHT.md` — copyright notice
- `LICENSE.md` — open-source license
- `SECURITY.md` — security policy
- `robots.txt` — crawler rules

## Deployment
This project is deployed to GitHub Pages from the `main` branch.

## Local Preview
Open `index.html` directly in a browser or run a local static server if needed.
